## Seed recovery: reproducible failure, not a pass

`chain/test-seed-recovery.sh` and its Python harness create a daemon and two wallet
RPC processes inside one `--network none` container. They use new disposable keys,
mine private test coinbases, and require explicit equality of address, history,
balance and unlocked balance after restoring the mnemonic into a separate wallet.
The original cache and key file must be deleted before restore; the recovered
wallet must also close/reopen without changing the result. No real keys or funds
are used. Mnemonic output stays in memory, not the committed evidence.

**The current thirteen-patch binaries fail before restore**, during the original
wallet's first funded refresh:

> Unexpected hard fork version v16 at height 1. Make sure your wallet is up to date

[Failure trace](evidence/2026-09-12/seed-recovery-failure.log). The assertions after
this failure have **not executed**, so seed recovery remains unverified. This
regression runner is deliberately not added to passing CI until the fix is verified.
An initial harness attempt without `--offline` returned daemon `BUSY`; the runner
now uses the existing offline mode for this single-node test.

Root cause found in the pinned source: `tools::check_block_hard_fork_version` in
`src/wallet/wallet2.cpp` compares a version identifier against the number of fork
table entries and indexes by `version - 1`. Meownero has two mainnet entries,
`{v1@0, v16@1}`. The helper therefore treats v16 as newer than the wallet even
though wallet and daemon share the correct table. No version-check bypass was
added to the harness. Existing historical wallet/storage tests did not exercise
this live block-refresh path.

A narrow lookup-by-version fix and activation-boundary regression tests are
**drafted but unbuilt and uncommitted, outside this repository**, in:

`<agent-scratch>`

Only `src/wallet/wallet2.cpp` and `tests/unit_tests/hardfork.cpp` are new tracked
scratch edits. Preserve the pre-existing untracked `tests/data/wallet_*` artifacts.
No patch 0014 is exported. The thirteen committed patches remain unchanged.
