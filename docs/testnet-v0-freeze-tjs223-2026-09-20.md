# Meownero testnet v0 feature freeze and maturity audit

2026-09-20. TJS-223. Consensus role. Read-only source/evidence audit, with this document as the sole repository addition. Snapshot at 22:01 UTC, repository HEAD `4ab9148d560004b85fce6376593cafa3f7a69cab`, branch `m1/september-7-verification`, plus existing dirty files. This is an agent recommendation and finite engineering cutoff, not an external audit, architecture signature, 90-second GO, or public-launch authorization.

Freeze v0 around the existing C++ node, its RingCT payment system, selected 9 MEOW/90-second experimental profile, native RandomX/DAA, wallet RPC recovery, and the bounded local P2Pool port once independently accepted. Defer FCMP++, CARROT, RandomX v2, a Zcash lineage change, and Ethereum-derived protocol additions. Their potential merits do not establish an integrated, reviewed Meownero implementation. The next deliverable is a repeatable isolated multi-node test network with one operator recipe and evidence for launch, sync, mine, send, restore, reorg and restart.

“Include” below fixes scope; it does not declare every acceptance check passed. Test coins carry no value. Existing public-testnet identity, bootstrap and release gates remain explicit. No mainnet work is authorized by this document.

## Frozen v0 set and invariant boundaries

The included set is exactly C1–C9. C8 is the sole in-flight feature admission, through existing TJS-187 → TJS-224 → QA ownership. A failed F4 review returns to the writer; this document neither drops that requested behavior nor substitutes a custodial pool. Solo mining remains the basic node path while F4 acceptance proceeds.

1. Use the existing C++ selected binary and explicit peers. This preserves the accepted implementation and avoids making Rust parity or another chain architecture a prerequisite.
2. Keep RingCT ordinary payments and the demonstrated wallet RPC interface. This gives v0 a usable payment/recovery path now, without calling it FCMP or making an anonymity guarantee on a tiny chain.
3. Keep 9/90 as the experimental selected profile, exact 12-dp amounts and perpetual subsidy, with the accepted 12/120 binary retained as a separately launched fallback. A fallback switch is a separate fresh test chain and requires a matching pool port/review; never mix profiles or silently switch a data directory. No monetary-policy redesign.
4. Preserve native RandomX, DAA, floor 1, cumulative-work selection, penalties and fees. This bounds consensus change and retains relevant acceptance. No automatic raised floor or parameter-GO inference.
5. Require the accepted local pool port, once verified, with its pinned sharechain and trusted loopback daemon. This supplies the requested noncustodial mining behavior without adding AuxPoW.
6. Deliver source/overlay manifests, exact binaries, public chain metrics and an operator recipe with disposable local keys and isolated data directories. Existing RPC metrics suffice for v0; an explorer frontend and new GUI are deferred.

| Delta or boundary | Assumptions requiring preservation or targeted acceptance |
| --- | --- |
| Flat reward/spacing | Reward independent of accumulated tally; zero genesis; exact integer weight penalty; fees counted once; main and alt chains saturate rather than wrap.
